本地模型

首次使用：到 ollama.com 安装并启动 Ollama，命令行执行 ollama pull qwen3:8b 拉取一个模型（约 5GB），再点「检测」即可自动填入。

💡 模型怎么选（离线体验的关键）：日常文稿 / 简历 / 模板生成推荐 qwen3:8b 起步——1.5b 以下的小模型写长文书会明显空洞、跑题；qwen3、deepseek-r1 等「思考型」模型会先思考再给正文，云笺已自动剥离思考内容；若正文仍不完整，给 Ollama 设置环境变量 OLLAMA_CONTEXT_LENGTH=8192 后重启 Ollama。

🔒 本地模式全程在你的电脑上离线运行，文稿内容不会离开本机、不消耗任何 token；速度与效果取决于模型大小和电脑配置。若浏览器控制台报跨域错误，给 Ollama 设置环境变量 OLLAMA_ORIGINS=* 后重启即可。
