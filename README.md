# ☁️ 云笺 · 个人文稿全能助手

一个**纯前端**的写作与学习工具箱：不用来回切换各种 AI 网页，粘贴文本 → 点一下 → 拿结果。数据只存在你自己的浏览器里。

**双模式 AI 引擎**：🌐 在线 DeepSeek API（能力强，适合长文档 / PPT）与 💻 本地 Ollama 开源模型（免费、不耗 token、断网可用）二选一，顶栏一键切换，长文本自动提示省 Token 方案。

**多媒体创作全链路**：🎙️ 录音/音频 → faster-whisper 本地转写 → PromptSlim 自动清理口语废话 → 文稿润色 / 降重 / 审校 / 思维导图 → 一键生成 PPT（导出 .pptx）、短视频分镜脚本与 SRT 字幕。

**📦 提示词 & 模板包**：内置 14 条精选提示词（文稿 / 录音整理 / PPT / 答辩模拟四大分类），支持 AI 生成专属提示词、JSON 包导入导出（可分发 / 售卖）。

**📖 内置使用指南**：首次访问自动弹出（3 步上手 + 17 模块速查 + 常见问题），小云提供分步新手引导；

**🎤 互动答辩模拟 + 📋 批量处理**：AI 评委逐题提问、点评回答漏洞、追问到底，结束出评分与改进报告；多篇文档 / 多段录音排队批量执行摘要、润色与字幕校对，串行防限流、合并导出。

其他能力：

- **⚡ 文本瘦身（省 Token）**：输入框下方一键「⚡ 瘦身」——纯本地规则压缩，不耗 AI、不花钱：去多余空白与空行、连续重复行/重复标点清理、口水词与结巴叠字压缩，长文本一般能省 10%～30% token；**原文自动备份，一键「↩ 还原」**；SRT 字幕的时间轴行、``` 代码块、Markdown 表格自动识别并跳过，不会误伤；**自动瘦身**（设置中可开关，默认开启）：2000 字以上的文本发送前自动压缩「发给 AI 的副本」——只清空白与重复行、不改内容，输入框原文保持不变，生成结果旁会显示本次省下的比例与 tokens；输入框字数旁新增 **token 实时估算**（如「1,234 字 · ≈740 tokens」）。设计灵感来自开源项目 [Headroom](https://github.com/chopratejas/headroom)（可逆上下文压缩层，原文永远保留在用户手里）与微软 [LLMLingua](https://github.com/microsoft/LLMLingua)（提示压缩，先去低信息量内容）的本地规则版实现
- **🧠 提示词 few-shot 示例**：思维导图、标题命名等对输出格式最敏感的任务，在提示词中内置了精炼的格式示例（示例锚定格式比规则更稳），输出可直接导入 XMind、复制即用。写法参考开源项目 [prompt-lib](https://github.com/castorini/prompt-lib) 的示例工程实践

- **🎯 补充要求**：写明字数、语气、受众等硬性要求（如「300字以内，正式一些」），AI 会严格遵守
- **💡 追问微调**：生成后一键追问——再简短点 / 更详细 / 更正式 / 更口语 / 换个写法，AI 基于上一版结果继续优化
- **🌐💻 双模式：在线 API + 本地离线**：顶栏下拉框二选一——
  - **在线 API 模式（DeepSeek）**：填 API Key 即用，能力更强，适合长文档、PPT 生成、字幕翻译等重活（消耗 token）；
  - **本地离线模式（Ollama）**：接 [Ollama](https://ollama.com) 本地开源模型（如 qwen3、deepseek-r1），**完全免费、不消耗任何 token、断网也能用**，适合日常文稿、录音整理；设置里点「🔍 检测」自动获取已装模型，也支持 LM Studio 等 OpenAI 兼容端点；
  - **自动省 Token 联动**：在线模式下检测到 2000 字以上长文本，先弹窗提示「可以切换本地模型，不消耗 Token」，一键切换并继续任务（可勾选不再提示）；**Token 压缩模块按模式默认联动**——在线 API 默认开启自动瘦身（省 token 就是省钱），本地模型默认关闭（本地不计费，不需要省 token），可随时手动开/关；
  - 双模式切换全量记忆，状态栏实时显示当前模式与模型；本地模式下余额/累计用量自动隐藏，用量标签显示「本地模型 · 不计费」
- **📥 一键应用到输入框**：润色 / 降重改写 / 修正后全文 / 字幕等结果一键替换输入框原稿（自动截掉对照表，只取正文），再点一次即可撤销——「生成 → 应用 → 继续编辑」一气呵成
- **🤖 AI 小助手「小云」**：右下角悬浮的**萌系写作搭子**（蓝发小可酱 24 款 Q 版表情随机换装、会浮动蹦跳、主动教学引导），根据你粘贴的内容**智能提示**该用哪个功能（识别长文本、聊天记录、请假/邮件/简历、英文文本、论文、课堂笔记、分镜脚本等场景），说话亲切可爱，也能随时问答写作问题
- **💰 Token 用量与余额**：每次生成后在结果栏显示本次消耗（输入 / 输出 / 合计 tokens，本地模式标注不计费）；顶栏实时显示 DeepSeek 账户余额（点击刷新，仅在线模式显示）；「设置」里可查询余额明细、查看本机累计用量（可清零，只统计在线 API 调用）；余额不足时会主动提醒并建议切换本地模型；配合「⚡ 文本瘦身」还能在发送前就把 token 省下来
- **🪟 毛玻璃工作台**：工作台半透明 + 背景模糊，壁纸隐约透出、文字依旧清晰，壁纸栏可一键开关（本地记忆）
- **🎨 壁纸栏**：14 款壁纸——7 款渐变主题（极光紫 / 樱花粉 / 晴空蓝 / 薄荷绿 / 暖阳橙 / 星夜紫 / 墨夜蓝）+ **7 款插画壁纸**（樱花季 / 窗边日常 / 星河入梦 / 花窗和服 / 黄昏电车 / 夏日水花 / 海风少女，每款自动搭配主题色）+ **自定义壁纸上传**（本地图片压缩后存进浏览器 IndexedDB，不上传服务器，可存多张、悬停删除，浓度与毛玻璃照常可用）；插画壁纸支持**浓度滑杆**自由调节（10%～100%），调淡了完全不遮挡工作区，设置本地记忆
- **📥 拖拽导入**：把 .txt / .srt / .md / .vtt / .csv 文件直接拖进输入区即可导入内容（可一次多个文件）
- **⬇ 结果导出与一键应用**：所有结果可复制、**导出为 .md 文件**（附字数统计）；润色 / 降重改写 / 修正后全文等结果还能**一键替换回输入框**（再点一次撤销）
- **流式输出**（打字机效果，可随时停止）、`Ctrl+Enter` 快捷执行、**历史记录本地保存**（最多 200 条，支持**关键词搜索**，可回看 / 删除 / 清空；带「应用到输入框」的记录回看后也能直接应用）

## 快速开始

### 1. 选择 AI 模式（二选一）

**方式 A · 在线 API 模式（DeepSeek）**：前往 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 注册并创建一个 API Key（形如 `sk-...`）。

**方式 B · 本地离线模式（Ollama，免费）**：
1. 到 [ollama.com/download](https://ollama.com/download) 下载安装 Ollama（Windows 安装完会自动在后台运行）；
2. 打开命令提示符，执行 `ollama pull qwen3:8b` 拉取一个开源模型（约 5GB，一次即可）；
3. 启动云笺 → 点右上角「设置」→ AI 模式选「本地离线模式」→ 点「🔍 检测」自动获取已装模型 → 保存。

**（可选）本地语音转写服务（faster-whisper，供「录音转写」模块使用）**：
1. 安装 [Python 3.9+](https://www.python.org/downloads/)（勾选 Add to PATH）；
2. 双击 `tools\启动转写服务.bat`（首次自动 `pip install faster-whisper`），或手动执行 `pip install faster-whisper` 后运行 `python tools/whisper_server.py`；
3. 保持窗口开启，云笺「🎙️ 录音转写」页会自动检测连接。首次转写时自动下载识别模型（base 约 140MB）。

### 2. 启动

**方式 A（推荐）：** 双击 `start.bat`（需要已安装 Node.js），浏览器打开 <http://localhost:8787>

**方式 B：** 直接双击 `index.html` 用浏览器打开（Chrome / Edge）

### 3. 配置并开始

点右上角 **⚙️ 设置**：
- 在线模式：粘贴你的 DeepSeek API Key 并保存；
- 本地模式：保持默认地址 `http://localhost:11434/v1`，点「🔍 检测」选择模型；
- 也可以勾选 **演示模式**，不调用任何 API 先体验完整流程。

之后随时可以用顶栏下拉框在两种模式间一键切换。

## 隐私说明

- API Key 仅保存在你本机浏览器的 localStorage 中，请求由浏览器**直接**发往 DeepSeek 官方接口，不经过任何第三方服务器；
- **本地 Ollama 模式完全离线**：文稿内容只发往你本机的 `localhost:11434`，不经过任何网络，断网也能正常使用；
- **录音与音频文件不出本机**：录音转写只把音频发往你本机的 faster-whisper 转写服务（`127.0.0.1:8765`），全程离线、不消耗 token、不上传任何服务器；
- 历史记录同样只保存在本机浏览器，清除浏览器数据会一并清除。

## 剪映字幕导入说明

「AI 剪辑助手」提供两种给剪映用字幕的方式：

1. **导入 .srt 文件**：字幕纠错润色 / 文稿转字幕完成后，点结果工具栏的「⬇ .srt 字幕」下载，在剪映「素材 → 字幕 → 导入字幕」即可使用；
2. **文稿匹配**：点「⬇ 剪映文稿.txt」下载纯文本，在剪映「文本 → 智能字幕 → 文稿匹配」中粘贴，剪映会自动对齐时间轴（更精准）。

  "name": "你的提示词包名称（如：考研复试锦囊包）",

- `category` 四选一：`doc`（文稿模板）/ `audio`（录音整理）/ `ppt`（PPT 提示词）/ `defense`（答辩模拟），其他值会归入 `doc`；
- `content` 中写 `{{input}}` 占位符，用户「▶ 使用」时粘贴的内容会替换到该位置；不写占位符则用户内容作为待处理文本附加在提示词后；
- 导入时自动校验：缺 `title` / `content` 的条目跳过，与库中「标题+正文」完全相同的条目跳过（防重复导入），完成后显示新增/跳过统计；
- 云笺内「⬇ 导出全部」或单条卡片「⬇」导出的 JSON 即为此格式，可直接作为商品交付；建议在商品描述中注明「导入方法：云笺 → 📦 提示词库 → 📥 导入 JSON 包」。

## 常见问题

- **提示 401**：API Key 填错或已过期，到设置里重新填写。
- **提示 402**：DeepSeek 账户余额不足（顶栏和设置里可查看余额）；不想充值可以切到本地离线模式继续用。
- **提示网络错误**：检查网络；如在受限网络环境，可在设置的「API 地址」中填入你的中转 / 代理地址；断网时可直接切换本地离线模式。
- **余额显示 "--"**：使用官方地址时点击顶栏余额徽章即可查询；使用第三方中转地址时，中转服务通常不支持余额查询接口，属正常现象。
- **模型选择**：`deepseek-chat` 速度快，日常写作推荐；`deepseek-reasoner` 深度思考，适合长文摘要，稍慢。
- **本地模式「无法连接本地模型服务」**：① 确认 Ollama 正在运行（开始菜单打开 Ollama，或命令行执行 `ollama serve`）；② 已拉取模型（`ollama pull qwen3:8b`）；③ 如果云笺页面不是从 `localhost` 打开的，给 Ollama 设置环境变量 `OLLAMA_ORIGINS=*` 后重启。
- **本地模式提示「模型不存在」**：先在命令行执行 `ollama pull 模型名` 拉取，再到设置里点「🔍 检测」重新选择；检测不到时检查服务地址是否为 `http://localhost:11434`。
- **本地模式能用哪些模型**：日常文稿推荐 `qwen3:8b`（中文好、体积适中）；想体验推理可拉 `deepseek-r1:7b`；电脑配置一般可用更小的 `qwen3:4b`。**不建议 1.5b 以下的模型写简历 / 模板等长文书**——小模型会输出空洞、跑题的内容。LM Studio / llama.cpp 等 OpenAI 兼容服务把地址填成对应端点（如 `http://localhost:1234/v1`）即可。
- **本地模式输出空洞 / 一堆"思考" / 正文不完整**：① qwen3、deepseek-r1 等思考型模型会先输出一大段思考——云笺已自动剥离思考只显示正文；② 若正文被截断，给 Ollama 设置环境变量 `OLLAMA_CONTEXT_LENGTH=8192` 后重启 Ollama；③ 复杂文书任务（简历 / PPT 大纲）请用 8b 及以上模型，小模型能力不够时切在线模式。
- **录音转写未连接转写服务**：确认 `tools\启动转写服务.bat` 已运行且窗口保持开启；确认已安装 Python 并执行过 `pip install faster-whisper`；服务地址默认 `http://localhost:8765`，可在录音页修改。
- **录音转写识别效果差 / 有错字**：换更大模型——重启转写服务时执行 `python tools/whisper_server.py --model small`（更准、更慢）；录音时靠近麦克风、减少背景噪音；识别语言手动指定比自动检测更稳。
- **录音转写支持哪些文件**：MP3 / WAV / M4A / AAC / FLAC / OGG / WebM / AMR 等常见格式，也可直接在页面里麦克风录音；音频只发往本机 127.0.0.1 转写服务，不上传任何服务器。
- **视频功能**：需要通过 `start.bat`（本地服务器）使用；视频全程在本机处理，不上传。「提取视频内嵌字幕」只对带字幕轨的视频（如部分 MKV）有效，普通 MP4 无内嵌字幕时可改用「文稿转字幕」。
